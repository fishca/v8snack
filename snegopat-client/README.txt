Снегопат (x64) для Конфигуратора 1С:Предприятие 8.3 — установка без агента

Нужно: Windows, 64-битная платформа 1С:Предприятие 8.3. Доступ в интернет не нужен.

Запускайте Снегопат только с 64-битным Конфигуратором 1С. 32-битный Конфигуратор не поддерживается.
Разрядность самой Windows не определяет разрядность установленной платформы 1С: выбирайте именно 64-битный Конфигуратор.
Папка x64\lib\x86 нужна загрузчику starter.exe и не означает поддержку 32-битного Конфигуратора. Не удаляйте её.

Установка
1. Скопируйте папку x64 в любое место, где у вашей учётной записи есть право записи
   (например, C:\Snegopat\x64 или D:\Tools\Snegopat\x64). Путь без лишних вложенностей.
2. Закройте все Конфигураторы и запустите x64\starter.exe (двойной щелчок).
3. Откройте Конфигуратор — Снегопат загрузится.
4. Закончив работу, остановите starter.exe (процесс остаётся в памяти до выхода из Windows
   или до остановки в Диспетчере задач). Для автозапуска положите ярлык starter.exe в автозагрузку.

Обновление
Закройте Конфигураторы, остановите starter.exe и замените папку x64 новой версией целиком.
Ваши настройки лежат в x64\data\Snegopat\settings\ — перед заменой сохраните эту папку и верните её на место.
Если вы меняли x64\logs\diag.ini (переключатели диагностики), сохраните и его: новая версия принесёт файл с настройками по умолчанию.
Номер версии — в файле x64\version.json (поле ours).

Где что лежит
x64\data\Snegopat\settings\   — ваши настройки (создаются сами)
x64\logs\                     — журналы; ошибки скриптов Снегопата — x64\logs\script-errors.txt
Подробный журнал работы — x64\logs\script-log.txt (включён, занимает не больше ~32 МБ).
Ошибки показываются и в окне сообщений Конфигуратора. При обращении за помощью приложите папку x64\logs, версию платформы 1С и опишите, что делали.

Сброс настроек к начальным
Закройте Конфигураторы, удалите папку x64\data\Snegopat\settings и запустите Конфигуратор снова: настройки вернутся к начальным (из x64\data\Snegopat\defaults).

Windows 11 24H2 и новее: не работают горячие клавиши и окна Снегопата
Признаки: Ctrl+M ничего не делает, не открываются список скриптов и «Панель окон», нет сообщения о подключении Core.As.
Возможная причина (подтверждена не у всех): Windows 11 24H2 по умолчанию подменяет старый движок JScript на JScript9Legacy, а скриптовые аддины Снегопата написаны для старого.
Что попробовать: закройте Конфигураторы, дважды щёлкните win11-fix\JScript_Win11_24H2_Fix.reg (подтвердите внесение в реестр) и откройте Конфигуратор снова. Изменение действует только для вашей учётной записи (права администратора не нужны); отмена — win11-fix\JScript_Win11_24H2_Undo.reg. Учтите: движок подменён из-за уязвимостей в старом JScript, откат возвращает его для всех программ вашей учётной записи, которые его используют.
Если не помогло (особенно если нет сообщения о подключении Core.As): запустите x64\starter.exe до Конфигуратора и проверьте, что стартёр и Конфигуратор запущены с одинаковыми правами (не «от администратора» только один из них); посмотрите, не блокирует ли файлы x64\lib\x64 антивирус.
Для разбора пришлите папку x64\logs, номер сборки Windows (команда winver) и командную строку Конфигуратора (Диспетчер задач, колонка «Командная строка»).

Для разработчиков
Папка dump-tools\ — набор для снятия и сверки дампов vtable платформы 1С при переносе Снегопата на новую версию платформы (инструкция — dump-tools\README.md). Для обычной работы Снегопата не нужна.
