# Функции, отключённые на новых платформах, и как их включить

Файл восстановлен 2026-11-06 по коду и `docs/ISSUES.md` (оригинал утерян). Сюда сводятся
функции, которые по умолчанию выключены при работе на 8.3.27/8.3.28/8.5+ — с причиной,
способом включения и ссылкой на код. Управление включением — `logs/diag.ini`
(см. `tools/ADAPT.md`, §1).

## 1. Отключённые перехваты и функции

### п. 1.1 — `hook.colors`: скриптовый перехват раскраски строк

**Что.** Перехват `ITextExtColors.getColors` (раскраска синтаксиса строки, группировки `//{ //}`,
заливка фона многострочных строк) силами скрипта (`engine/sqlcolors.as`).

**Почему выключен.** Платформа вызывает `getColors` из фонового потока редактора (txtedt)
параллельно с главным потоком, а Core.As не допускает параллельного входа в скрипты:
на 8.3.27 — зависания и нативные падения при наборе; на 8.3.17 — падение в `core_as.dll`
(разбор дампа 2026-10-03, поток не главный, стек `txtedt → getColors → ловушка`).
Код: `sqlcolors.as`, ветка включения скриптового перехвата (комментарий перед `diagHook("colors", false)`).

**Как сейчас работает раскраска.** На x64 перехват выполняют нативные «ворота» —
`lib/x64`-близнецы `modules/snegopat/lib/x64/snegopat_colors.dll` (8.3, ищет `nuke83.dll`)
и `snegopat_colors85.dll` (8.5, ищет `nuke85.dll`), без входа в скрипты. Скриптовый хук — резерв.

**Как включить.** `logs/diag.ini`: `hook.colors=on` (или файл-флаг `logs/hook-colors.on`).
Состояние на 8.5: перехват встаёт, падений нет (проверено 27.10) — включение по умолчанию
после визуальной проверки, см. `docs/ISSUES.md` P0-1.

### п. 1.2 — автосохранение профиля: не по таймеру

**Что.** Периодическая запись профиля каждые 5 с.

**Чем заменено.** Запись по изменению с паузой: аддин `profile_autosave.js` пишет профиль,
когда счётчик изменений `profileRoot.changeCount` (com_profile.as) сдвинулся, а не по таймеру.
Код: `addons/std/main.js:45` (комментарий при загрузке аддина), `addons/profile_autosave.js`,
счётчик — `engine/com_profile.as`.

### п. 1.3 — авто-ответы при перезапуске по F5 (DebugSilence, silence.js)

**Что.** Автоматическое подтверждение вопросов «Перезапустить предприятие» и «Обновить базу
данных» при перезапуске предприятия из отладчика.

**Почему выключено.** Автоматическое подтверждение обновления базы небезопасно для пользователя
(структурные изменения применяются без вопроса).

**Как включить.** Макрос аддина silence: «Вкл/выкл вопросов при перезапуске во время отладки»
(`silence.js:644`) — переключает настройку `use` (`sillenceDebugModeHelper.set`, по умолчанию
`use=false`, `silence.js:515`).

### п. 1.4 — `initTextAreaModifiedTraps()`

**Что.** Перехват «текст области изменён» (использовался автосохранением `Autosave.js:270`,
`AutoSaveModule`).

**Почему выключен.** Вызов закомментирован в `engine/main.as:38` (история: падения на новых
платформах, включая 8.3.28+); механизм частично живёт в `engine/synedit.as`.

**Как включить.** Раскомментировать вызов в `main.as:38` — **только после проверки** на целевых
платформах; см. `docs/ISSUES.md` P1-2.
