# v8snack

Доработка заброшенного «Снегопата» под 64-битный Конфигуратор 1С:Предприятие 8.3.

Снегопат — расширение конфигуратора 1С: скриптовые аддины, свой список автодополнения,
панель окон, diff, закладки и десятки других мелочей. Оригинальный проект не развивается
и на новых платформах не работает; здесь лежит рабочая x64-сборка, доведённая до
состояния «распаковал и работает»: без агента, без интернета, с инструкцией на русском
и отдельным фиксом для Windows 11 24H2.

## Что внутри

```
snegopat-client/
  x64/            сам клиент: starter.exe, движок (lib/), модули (modules/), шаблоны,
                  настройки по умолчанию, version.json
  win11-fix/      .reg для Windows 11 24H2+ (вернуть старый JScript вместо JScript9Legacy) и откат
  dump-tools/     снятие и сверка дампов vtable при переносе на новую версию платформы
  README.txt      подробная инструкция: установка, обновление, диагностика, сброс настроек
```

## Требования

- Windows и **64-битный** Конфигуратор 1С:Предприятие 8.3. 32-битный Конфигуратор не
  поддерживается; разрядность самой Windows при этом не важна.
- Доступ в интернет не нужен.

## Установка (кратко)

1. Распаковать архив, скопировать папку `x64` в место, где есть право записи
   (например `C:\Snegopat\x64`).
2. Закрыть все Конфигураторы, запустить `x64\starter.exe`.
3. Открыть Конфигуратор — Снегопат загрузится.
4. Windows 11 24H2 и новее: если не работает Ctrl+M и не открываются окна Снегопата —
   применить `win11-fix\JScript_Win11_24H2_Fix.reg` (откат — `JScript_Win11_24H2_Undo.reg`).

Остальное — в `snegopat-client/README.txt`: обновление, где лежат настройки, журналы,
сброс настроек, что приложить при обращении за помощью.

## Отказ от ответственности

Проект не связан с фирмой «1С». «Снегопат» — сторонний проект, права на него принадлежат
его авторам; здесь распространяется доработка. Расширение конфигуратора работает внутри
чужого процесса и может привести к потере данных — используйте на свой риск и держите
резервные копии.
