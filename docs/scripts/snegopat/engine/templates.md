## `snegopat/engine/templates.as`

- Язык: **AngelScript**, строк: **97**, объявлений: **4**
- Назначение: Автоподключение файла шаблонов текста 1С, поставляемого со Снегопатом (x64/templates/ТсРазработкаШаблоны1с8.st). При запуске Конфигуратора: если файл есть и в списке файлов шаблонов 1С (профиль 1С, раздел TxtEdt, ключ AutoPlacementFilesRU1) его ещё нет — дописывается. Файл с таким же именем из другого места считается уже подключённым (шаблоны не дублируются).
- Состав: func — 4

- `string tplRootDir()` — Корень Снегопата (на два уровня выше папки модуля: <корень>\modules\snegopat\) с прямыми слэшами и без завершающего
- `void tplSetPlatformValue(IProfileFolder&& pf, const string& key, const Value& val)` — Записать значение в профиль платформы (нет ключа — создать в базовом хранилище, как для списка файлов шаблонов)
- `void tplApplyPlatformOptions(IProfileFolder&& pf)` — Настройки, которые выставляются вместе с подключением нашего файла шаблонов
- `bool registerTemplateFile()`
