## 1. P0 — блокирующие для 8.5.1

### P0-1. Раскраска запросов на 8.5 выключена по умолчанию

**Симптом.** На 8.5.1 нет раскраски запросов, группировки `//{ //}` и заливки фона
многострочных строк. Пользователь видит «раскраски нет».

**Причина.** В `engine/sqlcolors.as` перехват цветов (`hook.colors`) по умолчанию включён
только на 8.3.17.x и 8.3.27.x; на остальных версиях — off (следствие старого падения
`TextDoc::setTextExtenderType`, 0xC0000005 в `core_as.dll`, `textwnd.as:329`).

**Проверено 27.10.** На 8.5.1.1529 с `hook.colors=on`: перехват встаёт
(«перехват 'colors': ВКЛ»), Конфигуратор живёт 20+ секунд, журнал — 582 строки, 0 ошибок,
падения `setTextExtenderType` нет. Нативная часть — `modules/snegopat/lib/x64/snegopat_colors85.dll`
(16 КБ) — на месте.

**План.**
1. Визуальная проверка на 8.5.1 с `hook.colors=on`: раскраска строк запросов, `//{ //}`,
   заливка фона (`hook.linebg`).
2. Если работает — включить `hook.colors` по умолчанию для 8.5 в `sqlcolors.as`
   (условие версии) и обновить комментарий в `diag.ini`/`README.txt`.
3. Если не работает — прогнать `snegopat.coloringProbe`/`coloringStress`/`coloringBackgroundProbe`
   (диагностика в `com_snegopat.as`), проверить загрузку `snegopat_colors85.dll`
   и раскладку `ITextExtColors`/`ITextExtBackColors` на 8.5 (дампы vtable, `dump-tools/`).
4. Регресс на 8.3.27 — раскраска не должна сломаться.

**Критерий готовности.** На 8.5.1 «из коробки» (без правки `diag.ini`) строки запросов
раскрашены, фон многострочных строк в тему тёмного редактора (без белой заливки),
журнал без ошибок.

### P0-2. Ошибки аддинов на 8.5 (snegopatwnd, wndpanel)

**Симптом (журнал 26.10).**
- `snegopatwnd.js:337` — `addins.byUniqueName('alteditors')` → null;
- `snegopatwnd.js:899` — «Объект не поддерживает это свойство или метод» (страница справки:
  `this.form.HelpTree`/`Document` ещё не инициализированы);
- `wndpanel.js:917` — `form` null (не загрузилась `wndpanel.epf`);
- «Скрипт snegopatwnd совершил пять ошибок и будет прерван».

**Текущее состояние.** В коде уже стоят защиты: `if (alt)` (snegopatwnd.js:337),
`try/catch` на `Document` (snegopatwnd.js:899+), `if (!form)` с внятным сообщением
(wndpanel.js:917+). Ошибки в журнале — от сборки до этих правок.

**План.**
1. Прогнать на 8.5.1 сценарии: открыть «Настройки Снегопата» (все страницы), справку,
   панель окон, внешние файлы; проверить `logs/script-errors.txt` после каждого.
2. Если `this.form.HelpTree` всё ещё падает — обернуть `process(hs.root.childs[...])`
   в проверку `this.form && this.form.HelpTree`.
3. Добавить эти сценарии в ручной чек-лист приёмки (см. §4).

**Критерий.** `script-errors.txt` пуст после сценариев.

### P0-3. `commandDescription` на 8.5 возвращает null

**Симптом.** В журнале: «нет описания команды {A1C0F2E4-…}/2». Короткий текст пункта
не пишется в описание команды (в 8.5 `ICommandService.commandDescription` для наших
команд пуст).

**Влияние.** Некритично: полный текст пунктов ставится через `updateState`/`setText`;
меню отрисовывается и работает.

**План.** Для 8.5 поставить `MM_DESCR_TEXT = false` (текст только через `setText`) либо
оставить как есть и убрать `diagAlways`-шум в `mmSetCommandText` (перевести на `diag`).
Проверить, что подписи пунктов «Снегопат» и «Настройки Снегопата» видны.

## 2. P1 — документация и отключённые функции

### P1-1. Отсутствуют `tools/ADAPT.md` и `tools/DISABLED-27.md`

На них ссылаются `diag.as`, `sqlcolors.as`, `silence.js`, `std/main.js`, `probe_ifaces.as`,
но в репозитории файлов нет. Из-за этого потеряна история отключённых функций.

**Что известно из кода:**
- п. 1.1 — `hook.colors` (перехват цветов) отключён на платформах кроме 8.3.17/8.3.27;
- п. 1.2 — `profile_autosave.js` пишет по изменению с паузой (счётчик `profileRoot.changeCount`),
  а не каждые 5 с;
- `silence.js:515` — вопросы о перезапуске по F5 показываются (включается макросом).

**План.** Восстановить оба документа в `tools/` по коду и истории (что отключено, почему,
как включить), добавить в них ссылки на `docs/ISSUES.md`.

### P1-2. `initTextAreaModifiedTraps()` отключён

`engine/main.as:38` — `//initTextAreaModifiedTraps();` (включается только из `synedit.as`).
Следствие — `Autosave.js:270`: `AutoSaveModule()` не переехал на этот механизм.

**План.** Выяснить причину отключения (история: падения на 8.3.28+), проверить на 8.3.27
и 8.5.1; если безопасно — включить и перевести автосохранение на него.

### P1-3. `coreas_runner_c check` с ключом `/f`

`ANALYSIS.md` 4.2: консольный компилятор ломается при указании `/f`; тесты обходят это,
запуская проверку без `/f`. **План.** Воспроизвести, найти причину (разбор аргументов
в `core_as_loader`), починить или задокументировать обход в `tests/README.md`.
